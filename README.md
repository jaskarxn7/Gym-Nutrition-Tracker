# Gym-Nutrition-Tracker
About Description: Fitness, nutrition, weight, and rules tracker built using HTML, CSS, and JavaScript.

 Gym & Daily Nutrition Tracker

A single-page web application I built to track daily calorie intake, macronutrients, body weight progress, workout splits, and personal fitness rules.

 What it does
- Dynamically renders navigation bar and highlight active page using ES6 JavaScript.
- Daily nutrition target calculations and remaining calorie tracker.
- Editable workout plans and fitness rules saved dynamically in the browser.
- Saves all entries across session pages locally using `LocalStorage`.

 Tech stack
- HTML & CSS
- JavaScript (ES6+)
- LocalStorage API
